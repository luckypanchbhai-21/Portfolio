# Lucky Portfolio

A modern premium portfolio website for Lucky, a freelance video editor. Built with React, Vite, Tailwind CSS, and Framer Motion.

## Install

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Content

Portfolio content lives in:

- `src/content/projects.js`
- `src/content/about.js`
- `src/content/contact.js`

Replace the sample Google Drive preview links, thumbnails, and contact details with Lucky's real assets.
